# PySh - An Python Object Oriented Shell Implementation
A custom program allowing you to interact with your operating system written in pure Python.

This shell implementation is based on the CodeCrafters   
["Build Your Own Shell" Challenge](https://app.codecrafters.io/courses/shell/overview). The result is a POSIX compliant shell that's capable of interpreting all your basic shell commands, running external programs ,and navigate through the os filesystem.

From this project I deepend my understanding of how shells work under the hood, of Python's `os` and `pathlib` modules, and how to use the registry design pattern to make large modules easily extensible.
